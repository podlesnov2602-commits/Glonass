# Glonass Navi

Новый адаптивный сайт GPS/ГЛОНАСС-мониторинга. Основная версия находится в ветке `main`; предыдущая сохранена в `archive/before-redesign-2026-10-12` и в истории Git.

## Что входит

- Главная страница: интерактивная демонстрация, отрасли, контроль топлива, сценарный калькулятор, комплектации, процесс подключения, FAQ, контакты.
- Три самостоятельных руководства в `guides/`.
- Форма составляет сообщение WhatsApp на подтверждённый номер +7 (775) 371-50-77. Отправку подтверждает посетитель в WhatsApp; сервер приёма заявок и CRM не имитируются.
- Доступная клавиатурная навигация, мобильное меню, адаптивные макеты, режим reduced motion.
- SEO: title/description, canonical, Organization JSON-LD, robots.txt, sitemap.xml.
- Оригинальные SVG-иллюстрации, системные шрифты, без загрузки внешних библиотек или аналитики в браузере.

## Размещение

Это готовый статический сайт: сборка и сервер приложений не требуются.
Корень публикации — корень репозитория. Веб-серверу нужны `index.html`, `assets/`, `guides/`, `privacy.html`, `404.html`, `robots.txt`, `sitemap.xml`. Служебные файлы тестирования публиковать не обязательно.

Домен `glonass-navi.kz` **не переключается этим коммитом**. Для замены текущего сайта нужно загрузить файлы на действующий хостинг либо подключить этот репозиторий к выбранному статическому хостингу. DNS, учётные данные и настройка публикации не включены.
Canonical и sitemap рассчитаны на production-домен. Предпросмотры желательно закрывать от индексации на уровне хостинга. На GitHub Pages можно использовать `main / (root)`; пути к файлам относительные. Перед production-настройкой проверьте редиректы старых URL по `docs/MIGRATION.md`.

## Проверки в GitHub

Workflow `Website quality` запускается при изменении `main` и проверяет:
1. Математику сценариев, границы ввода, кодирование сообщения, устаревший расчёт.
2. Внутренние ссылки, идентификаторы, метаданные, доступность статических ресурсов.
3. Chromium desktop/mobile: ширины 360–1440 px, переключатели, формы, меню, FAQ и страницы без JavaScript.

Скриншоты и HTML-отчёт сохраняются в артефакте `browser-report`.
Тест перехода в WhatsApp перехватывает запрос: сообщения не отправляются.

## Контент и редактирование

Основной текст: `index.html`. Дизайн: `assets/styles.css`. Поведение: `assets/app.js`. Формула и текст обращения: `assets/core.js`.
Подтверждённые контакты и источники: `docs/RESEARCH.md`.

Калькулятор показывает гипотетическую **валовую** экономию по выбранному проценту, не чистую прибыль и не результат клиента. Отзывы, цены и гарантированные проценты экономии не выдуманы. Карты и отчёты помечены как демонстрационные.
Правила обработки данных описывают фактическую механику этой версии. При добавлении сервера, CRM или аналитики обновите их вместе с реализацией.

## Визуальное обновление · 13 октября 2026

Новый минималистичный интерфейс: белые и графитовые поверхности, синие акценты, крупная типографика, анимированная продуктовая иллюстрация. Модуль `assets/experience.js` управляет движением, появлением блоков, прогрессом прокрутки и выбором аренды/покупки. Компонент `navi-contact` держит WhatsApp рядом при прокрутке. Анимацию можно остановить; системное reduced motion учитывается.

Главное предложение: оборудование можно взять в аренду, покупать его необязательно. Логотипы из раздела клиентов исходного сайта сохраняются в репозитории. Используются реальные изображения, без выдуманных названий и статуса партнёра.
