# Переход со старого сайта

Исходники обновлены в GitHub. Публикация на glonass-navi.kz — отдельный шаг на действующем хостинге.

1. Сохранить резервную копию текущего хостинга и базы WordPress перед заменой.
2. Разместить статические файлы по инструкции README, проверить HTTPS и правильный MIME для JS-модулей.
3. Настроить 301-редиректы известных разделов:
   - /kontakty/ → /#contacts
   - /o-kompanii/ → /#about (проверить фактический старый slug в WordPress)
   - /veb-monitoring-transporta/ → /#platform
   - /product-category/gps-monitoring/ → /#equipment
   - /product-category/datchik-urovnya-topliva/ → /guides/fuel-control.html
4. Экспортировать полный список старых URL из WordPress/sitemap, отдельно сопоставить статьи и карточки товаров. Не удалять индексируемые страницы без решения по каждому адресу.
5. Проверить телефоны и WhatsApp вручную, подтвердить текущие условия аренды и обслуживания.
6. Подключать аналитику/CRM только с реальными идентификаторами и обновлением описания обработки данных.
7. Проверить sitemap.xml, robots.txt, canonical и страницу 404 после публикации.

Автоматических изменений DNS, удаления базы, настройки хостинга или переноса старых материалов в этом обновлении нет.
